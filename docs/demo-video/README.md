# Line demo video

[Watch or download the narrated video](https://r2.grabfootage.com/line/2026-10-06/line-demo-01a1125c.mp4) · [GitHub copy](./line-demo.mp4)

The final film is 60 seconds at 1920 × 1080, 30 fps, with H.264 video and AAC narration. The file is approximately 6.4 MB.

It shows actual captured states from the localhost chat and the three deployed Lovable demo apps: claiming party supplies, checking in for the morning challenge, and saving a boba order. The edit uses screenshots with focused framing and transitions; it is not a continuous screen recording. Chat responses use Astra, and the demo build flow returns prepared app links.

Narration is included in the MP4. The separate source narration is in [demo-audio](../demo-audio/).
